# 受付システム 追加要望 実装計画書

- 作成日：2026-08-07
- 対象：`要望.md` の6件
- 結論：**全6件、実装可能**（外部機器側の変更は不要、すべて reception-app 側の修正で完結）

## 技術前提（調査結果）

- 構成：Laravel + Inertia.js + Vue 3 + Vite
- タブレット画面は全ページ `resources/js/Layouts/ReceptionLayout.vue` を使用（管理画面は AdminLayout + `localstorage.auth` ミドルウェアで別系統）
- スキャン画面は `resources/js/Pages/Delivery/Create.vue`（納品）と `resources/js/Pages/Pickup/Create.vue`（集荷）のスキャンモーダル。ほぼ同一実装
  - 映像：ラズパイ製スキャンツール（192.168.210.90:5001）の `/video_feed` を `<img>` で表示
  - 赤枠検出：Socket.io の `detection_state` イベント → `documentDetected` フラグ
  - 撮影後画像：スキャナーが上下逆さ設置のため `DEFAULT_ROTATION = 180` で回転表示済み
- 発注データ：`Delivery` ⇔ `InitialOrder`（中間テーブル `delivery_initial_order`、多対多）。品名＝`initial_orders.name`、品番＝`initial_orders.s_name`
- 電子印状態：`deliveries.sealed_document_image` の有無で判定（一覧のバッジ表示も同カラムを使用）

## 要望① タブレット画面の5分無操作でTOPへ自動リダイレクト

**可否：可能（小規模）**

現状、`ReceptionLayout.vue` に10分無操作でスクリーンセーバー（PR動画）を起動するタイマーが実装済み（`IDLE_MS = 10分`、行172）。タブレット画面は全ページこのレイアウトを使うため、ここに追加するだけで全画面に効く。管理画面は AdminLayout のため自動的に対象外。

**実装方法**
- `ReceptionLayout.vue` に第2タイマー（5分）を追加
- 発火時、現在ページがTOP（`route('home')`）以外なら `router.visit(route('home'))` を実行
- 既存のスクリーンセーバータイマー（10分）はそのまま維持
  - 結果の挙動：サブ画面で5分放置 → TOPへ戻る → さらに10分放置 → スクリーンセーバー起動
- 操作イベント（touchstart 等7種）によるリセットは既存の仕組みを共用

**留意点**
- スキャンモーダル表示中に5分経過するとスキャン途中でTOPへ戻る。ボタン操作でタイマーはリセットされるため実運用上は問題になりにくいが、必要ならスキャンモーダル表示中はリダイレクトを抑止する対応も可能（要判断）

## 要望② スキャン画面のボタンを「撮影 or スキャン」の一方だけ表示に変更

**可否：可能（小規模）**

現状は `Delivery/Create.vue`（行190-206）と `Pickup/Create.vue`（行120-136）に「手動撮影」（グレー）と「スキャン」（赤・`documentDetected` が false のときグレーアウト）の2ボタンが併存。

**実装方法**（両ファイル共通）
- 2ボタンを `v-if="documentDetected"` / `v-else` で1ボタンに統合
  - 赤枠検出中：「スキャン」ボタン（赤・`captureScan`）のみ表示
  - 未検出：「撮影」ボタン（青など・`captureManual`）のみ表示
- 検出状態バナーの文言も表示中のボタン名に合わせて修正（「スキャン」で撮影してください／「撮影」ボタンで撮影してください）
- ボタン切替時のガタつき防止のため同一サイズ・同一位置で切り替える

## 要望③ スクリーンセーバーの「画面をタップして受付を開始」を大きく目立たせる

**可否：可能（小規模）**

実装箇所は `ReceptionLayout.vue` 行143-147。現状は下部に小さめの点滅テキスト（text-lg）のみ。

**実装方法**
- テキストサイズを text-lg → text-2xl〜3xl 程度に拡大、パディング増
- 半透明背景（bg-white/15）→ 視認性の高いボタン風デザイン（例：白背景＋青文字、またはブランドカラーの塗りボタン＋影）に変更
- タップアイコン（指マーク）を追加し、animate-pulse は維持（または軽いバウンドに変更）
- 位置は bottom-12 から中央寄り（bottom-20〜24）へ調整も検討

## 要望④ Admin/Deliveries/Index に発注データの品名・品番を表示（他○件方式）

**可否：可能（中規模）**

**実装方法**
- コントローラー（`DeliveryController::adminIndex()` 行231-260）：
  - `Delivery::query()` に `with(['initialOrders:initial_orders.id,name,s_name'])` と `withCount('initialOrders')` を追加
  - ページネーション20件のままなので性能影響は軽微
- ビュー（`Admin/Deliveries/Index.vue`）：
  - テーブルに「品名・品番」列を追加
  - 表示ロジック：
    - 紐付け0件 → 「-」
    - 1件 → 「品名 / 品番」
    - 複数件 → 「品名 / 品番　他○件」（○ = initialOrders_count - 1）

## 要望⑤ Admin/Deliveries/Index の絞り込みに電子印状態を追加

**可否：可能（小規模）**

**実装方法**
- コントローラー（`adminIndex()`）：
  - フィルタパラメータ `seal_status` を追加
    - `sealed` → `whereNotNull('sealed_document_image')`
    - `unsealed` → `whereNull('sealed_document_image')`
  - `filters` の返却配列に `seal_status` を追加
- ビュー（`Index.vue` 行20-62 のフィルターフォーム）：
  - ドロップダウン「電子印状態：すべて／電子印済み／未押印」を追加
- 判定カラムは一覧バッジと同じ `sealed_document_image` を使用し、表示と絞り込みの整合を保つ

## 要望⑥ スキャン中のライブ映像も180度回転表示

**可否：可能（小規模）**

現状、撮影後のプレビューは `DEFAULT_ROTATION = 180` で回転済みだが、スキャン中のライブ映像（`/video_feed` の `<img>`、Delivery/Create.vue 行128-133・Pickup/Create.vue 行57-63）は未回転のため上下逆さに見えている。

**実装方法**（両ファイル共通）
- ライブ映像の `<img>` に `style="transform: rotate(180deg)"`（またはclass `rotate-180`）を追加
- ラズパイ側（スキャンツール）の変更は不要。フロントのCSSのみで完結
- 破線のスキャン枠オーバーレイは対称形のため影響なし
